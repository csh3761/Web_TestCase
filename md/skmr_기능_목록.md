# skmr.ifns.work 기능 목록 (동작별 정리)

DOM 스캔(로그인 후 최상위 버튼 22개 순회 클릭 + 사이드바 트리 전개)으로 확인한 실제 동작 목록.
트래픽 녹화가 아니라 화면(DOM) 기준으로 확인한 것이며, 네트워크 API 스펙까지는 포함하지 않음.
근거 데이터: `reports/skmr_login_dom_probe.json`, `reports/skmr_menu_discovery.json`, `reports/skmr_deep_menu_discovery.json`

## 1. LOGIN
- 아이디/비밀번호 입력 후 로그인 (`input[type='text']`, `input[type='password']`, `button.login-form__submit`)
- 비밀번호 표시/숨김 토글 (`login-form__password-toggle`)

## 2. NAV — 탐색
- 뒤로가기 / 앞으로가기 / 상위 폴더 *(방문 기록 없을 때 비활성 — 정상 동작 확인)*
- 새로고침 (목록 갱신)
- 부서문서함 / 그룹문서함 전환 (상단 workbox 탭 + 사이드바 트리 라벨 양쪽에서 가능)
- 최근 방문 폴더 (드롭다운으로 최근 이동한 폴더 목록)
- breadcrumb "바로가기" (현재 경로 표시/이동)

## 3. UPLOAD — 문서 업로드
- "문서 업로드" 버튼 → 모달 오픈
- 모달 내 동작: 파일 선택, 업로드, 취소, 닫기

## 4. SEARCH — 검색
- 통합검색 (툴바 검색창)
- 상세조건검색 *(통합검색 패널을 먼저 열어야 나타나는 하위 토글 — 중첩 구조)*

## 5. SIDEBAR / TREE — 폴더 트리
- 모든 폴더 접기
- 사이드바 고정 / 고정 해제
- 폴더 메뉴 고정 / 고정 해제
- 트리 항목 펼치기/접기 (체브론)
- 트리 구조 (실측, 총 29개 노드까지 확인):
  - **바로가기**: 공유받은 문서, 공유한 문서, 내 문서, 잠금문서, 즐겨찾기, 최근 작업 문서, 최신 문서
  - **휴지통**: 개인업무함(→ user_1), 부서업무함(→ QnA → seungho.choi의 폴더), 프로젝트업무함(→ IDS TFT, QnA TFT)
  - **부서문서함** → QnA → (02. 이미지, 03. 업로드, seungho.choi의 폴더, user1의 폴더 → user1_하위폴더, user2의 폴더, 대용량 영상)
  - **그룹문서함** → IDS TFT, QnA TFT

## 6. DASHBOARD — 대시보드 (`&view=dashboard`)
- 즐겨찾기 해제 (현재 대시보드가 기본 즐겨찾기 상태로 열림)
- 대시보드 편집
- 위젯 추가 *(클릭은 되나 위젯 선택 UI까지는 이번 스캔에서 못 잡음 — 후속 확인 필요)*

## 7. PERMISSION — 권한 요청 패널 (`&view=requests`)
- 탭: 받은 요청 / 보낸 요청
- 상태 카운트: 전체 / 요청 / 승인 / 반려 *(테스트 계정 기준 전부 0)*
- 검색: 요청자명 입력 → 조회

## 7-1. SETTINGS — 설정 (More options 하위)
- 테마
- 탐색기 표시 방식: 페이징 / 무한 스크롤 (전환)
- 로그아웃
- 닫기

## 8. RECENT DOCS — 최근·최신 문서 패널
- 탭: 최근 작업 문서 / 최신 문서
- 문서 항목별 동작(문서 단위 기능의 단서): **다운로드, 이름 변경, 즐겨찾기 추가, 상세 보기, 더보기**
  - → 다음 단계(문서 단위 기능 스캔)에서 실제 문서 우클릭 메뉴와 겹치는지 대조 필요

## 9. ADMIN — More options(케밥 메뉴)
- 전사관리자 *(new1, seungho.choi 두 계정 모두 클릭해도 새 화면/내용이 안 잡힘 — 권한 부족 또는 새 탭/창 오픈 여부 미확인, 후속 조사 필요)*
- 업무함 관리자 *(위와 동일한 상태)*
- 설정 → 7-1 참고

## 10. PROFILE — 내 정보
- 로그아웃

## 11. 미확인/다음 단계 필요
- **문서 단위 기능**: 실제 문서 업로드 후 행 우클릭 메뉴, 다운로드/삭제/속성 등 (다음 작업)
- 사이드바 트리 4단계 깊이 일부(`user1_하위폴더`, `그룹문서함 → QnA TFT`)는 5단계 이상 중첩이라 이번 스캔(3라운드 제한)에서 미전개
- 상세조건검색 패널 내부 세부 필드 (패널 진입 자체는 원래 되는데, 재실행 시 통합검색 토글 상태에 따라 열림/닫힘이 달라 안정적으로 못 잡음)
