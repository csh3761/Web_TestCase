====================================================================
 휴지통 정리 도구 README (Sys_Trash / User_Trash)
 작성일: 2026-09-28
====================================================================

바탕화면의 Sys_Trash.exe, User_Trash.exe 두 프로그램에 대한 안내문
입니다. 더블클릭으로 실행하는 콘솔 프로그램이며, 실행하면 검은 로그
창과 함께 자동으로 크롬 창이 뜨고 웹 화면을 직접 조작해 otcs 사이트의
휴지통 문서를 정리합니다.

--------------------------------------------------------------------
[요약]
--------------------------------------------------------------------
Sys_Trash.exe   - 관리자(전사) 휴지통 전체 정리 (고정 sysadmin 계정)
User_Trash.exe  - 로그인한 개인의 업무함 휴지통 정리 (ID/PW 직접 입력)
--------------------------------------------------------------------


====================================================================
1. Sys_Trash.exe (관리자/전사 휴지통 정리)
====================================================================
[기능]
otcs 사이트의 "관리자(전사) 휴지통" 화면에 고정 관리자 계정(sysadmin)
으로 로그인해서, 휴지통에 들어있는 문서를 전량 스크롤 → API 기준으로
정확한 건수(문서/폴더 구분)를 확인 → 문서만 체크박스 선택 → 완전 삭제
까지 자동으로 수행합니다. 폴더는 자동으로 선택에서 제외됩니다. 삭제
완료 알림창이 뜨면 감지만 하는 게 아니라 OK/확인 버튼까지 자동으로
눌러서 닫아줍니다(알림창이 안 닫힌 채 남으면 다음 동작을 막을 수
있어서, 실제로 클릭까지 하도록 되어 있습니다).

[실행 방법]
- 더블클릭하면 "1. 폴더 / 2. 문서" 중 처리 대상을 선택하라는 안내가
  나옵니다. 숫자를 입력하고 Enter.
- 로그인 계정은 config\trash_credentials.json에 저장된 고정 계정을
  사용하므로 ID/PW를 직접 입력할 필요는 없습니다.
- 실행하면 로그 창(콘솔)은 화면 왼쪽, 크롬 창은 화면 오른쪽으로 자동
  배치됩니다(로그와 실제 동작을 동시에 보기 위함). 터미널 환경에 따라
  이 배치가 안 될 수도 있는데, 그래도 삭제 기능 자체에는 영향이
  없습니다.

[주요 옵션 (cmd에서 실행 시)]
  --mode document              모드 선택 프롬프트 없이 문서 대상으로 바로 진행
  --select-only                 체크박스 선택까지만 하고 실제 삭제는 하지 않음(리허설용)
  --delete-selection-limit N    삭제 대상을 N건으로 제한(소규모 검증용)
  --hold-ms 1500                종료 전 화면을 N밀리초 동안만 유지하고 자동 종료

[로그/결과]
  reports\sys_trash.log, reports\sys_trash_report.json
  (스크린샷: reports\sys_trash_after_*.png)

[주의]
실제로 실행하면 관리자 휴지통의 문서가 "영구 삭제"됩니다. 되돌릴 수
없으니 처음 확인할 때는 --select-only로 먼저 리허설 후 실행하세요.


====================================================================
2. User_Trash.exe (개인 업무함 휴지통 정리)
====================================================================
[기능]
otcs 사이트에서 개인 계정으로 로그인해서, "내 업무함 / 부서 업무함 /
프로젝트 업무함" 3곳의 휴지통을 순서대로 돌면서 각 업무함에 있는
문서를 전량 스크롤 → API 기준 건수 확인 → 문서만 선택 → 삭제까지
자동으로 처리합니다. Sys_Trash.exe와 달리 로그인한 "그 사람 본인"의
휴지통만 대상입니다. Sys_Trash.exe와 마찬가지로 삭제 완료 알림창을
감지하면 OK/확인 버튼까지 자동으로 클릭해서 닫아줍니다.

[실행 방법]
- 더블클릭하면 "ID 입력:" 이 뜨고, 이어서 비밀번호를 별표(*)로 가려진
  채로 입력받습니다.

[주요 옵션 (cmd에서 실행 시)]
  --username 아이디 --password 비밀번호   프롬프트 없이 바로 실행
  --select-only                            선택까지만 하고 삭제는 하지 않음
  --login-only                             로그인 성공 여부만 확인

[로그/결과]
  reports\user_trash_login.log, reports\user_trash_login_report.json

[주의]
Sys_Trash.exe와 마찬가지로 실제 삭제 동작이며 되돌릴 수 없습니다.


====================================================================
공통 참고사항
====================================================================
- 두 도구 모두 실제 운영 사이트(otcs.ifns.devel)에 직접 접속해서
  동작합니다. 테스트 환경인지 반드시 확인 후 실행하세요.
- 둘 다 실제로 문서를 영구 삭제하며 되돌릴 수 없습니다. 처음 확인할
  때는 --select-only 옵션으로 먼저 리허설하는 것을 권장합니다.
- 옵션을 붙여서 실행하려면 cmd(명령 프롬프트)를 열고 아래처럼
  실행 파일 경로 뒤에 옵션을 붙이면 됩니다.
    "%USERPROFILE%\Desktop\Sys_Trash.exe" --mode document --select-only
    "%USERPROFILE%\Desktop\User_Trash.exe" --username 아이디 --password 비밀번호 --select-only
- 실행 결과 로그/리포트는 각 EXE가 있는 폴더의 reports 폴더에
  저장됩니다. 문제가 생기면 이 로그 파일을 먼저 확인해 주세요.
