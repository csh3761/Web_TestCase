	tep 3. File Upload Engine (업로드 실행)
	사이트의 드래그 앤 드롭 영역 구현 방식에 따라 아래 2가지 기법 중 하나를 적용합니다.

	기법 A (Input 요소 직접 주입 - Best):
		드래그 앤 드롭 영역 내부에 숨겨진 <input type="file"> 태그를 찾아 파일 경로를 직접 대입합니다.

	Python
	# Playwright 예시 (가장 깔끔함)
		page.locate('input[type="file"]').set_input_files('C:/path/to/file.pdf')
		기법 B (HTML5 Drag & Drop JS Injection):
		<input> 태그가 없는 순수 JS 이벤트 드롭존일 경우, DataTransfer API를 이용한 JavaScript 스크립트를 페이지 내에 주입하여 		드래그 앤 드롭 이벤트를 발생시킵니다.

	Step 4. Exception Handling & Logging (예외 처리 및 결과 저장)
		업로드 성공 여부(완료 팝업, DOM 변경 등)를 감지하여 엑셀 결과 컬럼에 Success / Fail을 기록합니다.
	
		네트워크 지연을 고려해 파일당 Retry(최대 3회) 로직 및 Timeout 설정을 적용합니다.

		최종 완료 후 upload_result_TIMESTAMP.xlsx 형태로 결과 리포트를 자동 생성합니다.

	웹 드래그 앤 드롭 방식이라 하더라도, 실제 웹 내부에는 파일 수용을 위한 HTML 요소가 존재합니다. 마우스 좌표를 건드리는 물리 	드래그 방식보다는 Playwright를 활용해 웹 DOM 요소에 파일 경로를 바로 밀어넣는 방식이 445개 문서의 무결성 확보와 속도 측면에	서 가장 압도적인 효율을 보여줍니다.
